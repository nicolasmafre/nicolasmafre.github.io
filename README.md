# Portfólio de Nícolas Martins Freitas

Este repositório contém o código-fonte do meu portfólio pessoal. A página foi recentemente reestruturada para ser **moderna, limpa e altamente performática**, construída como um arquivo único (`index.html`) utilizando **HTMX** e um Design System próprio embutido.

🌐 **Aceda ao site ao vivo:** [https://nicolasmafre.github.io/](https://nicolasmafre.github.io/)

---

## ✨ Novidades da Arquitetura Atual
- **Single File Architecture:** Estrutura unificada com o HTML, CSS e a lógica JavaScript embutidos num único ficheiro, garantindo máxima velocidade de carregamento e facilidade de manutenção.
- **HTMX Integrado:** Interatividade do lado do cliente utilizando `hx-on:click` para manipulação de estados e eventos, sem a necessidade de frameworks JavaScript pesados.
- **Segurança Anti-Spam:** O e-mail de contacto encontra-se codificado em Base64 no código-fonte e é apenas revelado através de uma interação segura com o HTMX, protegendo contra o rastreio de *bots*.
- **Tema Escuro/Claro (Dark/Light Mode):** Alternância fluida de temas gerida de forma nativa e guardada no `localStorage` do navegador.
- **Design Responsivo:** Layout adaptável de forma nativa para dispositivos móveis, portáteis e ecrãs de grandes dimensões, utilizando CSS Grid.
